# Cardgame

Учебный pet-проект: веб-клон карточной игры в духе Rise of Mythos.[cite:1]

## Статус

Проект находится в активной разработке.
Сейчас собран базовый клиент на Vite + React + TypeScript, настроены инструменты качества кода и начата сборка battlefield UI.[cite:328][cite:329]

## Что уже есть

- Клиентское приложение на Vite + React + TypeScript.[cite:328]
- Базовая структура проекта: `app`, `game`, `shared`, `pages`.[cite:162]
- Компонент карточки `Card` с пропсами и рендером списка карт.[cite:150]
- Составной компонент `Hero` и общий UI-компонент `HpBar`.[cite:19]
- Настроены Biome, Husky, lint-staged и `.editorconfig`.[cite:329][cite:330]
- Настроены alias imports для клиентского кода.[cite:274][web:172]

## Структура репозитория

- `client/` — фронтенд-приложение.
- `server/` — будущий backend.
- `docs/` — учебные материалы и заметки по проекту, если появятся позже.[cite:327]

## Запуск клиента

```bash
cd client
npm install
npm run dev
```
