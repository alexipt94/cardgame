# Cardgame

Учебный pet-проект: веб-клон карточной игры в духе Rise of Mythos.

## Статус

Проект находится в активной разработке.

Сейчас собран базовый клиент на Vite + React + TypeScript, настроены инструменты качества кода, реализована базовая сцена боя и заложена логическая модель центрального battlefield.

## Что уже есть

- Клиентское приложение на Vite + React + TypeScript.
- Базовая структура проекта: `app`, `game`, `shared`, `pages`.
- Компонент карточки `Card` с пропсами и рендером списка карт.
- Составной компонент `Hero` и общий UI-компонент `HpBar`.
- Настроены Biome, Husky, lint-staged, `.editorconfig` и alias imports.
- Реализован layout боевого экрана с разделением на зоны `4x1 + 4x10 + 4x1`: левая зона героя, центральная игровая область, правая зона противника или босса.
- Добавлены hero/boss UI-сущности на сцене боя через `HeroUIModel`.
- Центральное поле переведено из набора статичных клеток в логическую структуру данных: `Cell`, `CellEffect`, `Battlefield`, `createBattlefield()` и `getCell()`.
- `BattleFieldGrid` рендерит физическое поле из логической модели battlefield.

## Структура репозитория

- `client/` — фронтенд-приложение на React + TypeScript.
- `server/` — будущий backend.
- `docs/` — заметки и дополнительные материалы по проекту.

## Запуск клиента

```bash
cd client
npm install
npm run dev
```
