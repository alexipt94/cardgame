Сейчас собран базовый клиент на Vite + React + TypeScript, настроены инструменты качества кода, реализована базовая сцена боя, заложена логическая модель battlefield и покрыта unit-тестами. Введён BattleState и первый reducer. Клетки поля интерактивны: клик занимает клетку и визуально её отображает.

Клиентское приложение на Vite + React + TypeScript.

Базовая структура проекта: app, game, shared, pages.

Компонент карточки Card с пропсами и рендером списка карт.

Составной компонент Hero и общий UI-компонент HpBar.

Настроены Biome, Husky, lint-staged, .editorconfig и alias imports.

Реализован layout боевого экрана с разделением на зоны 4×1 + 4×10 + 4×1: левая зона героя, центральная игровая область, правая зона противника или босса.

Добавлены hero/boss UI-сущности на сцене боя через HeroUIModel.

Центральное поле переведено из набора статичных клеток в логическую структуру данных: Cell, CellEffect, Battlefield, createBattlefield() и getCell().

BattleFieldGrid рендерит физическое поле из логической модели battlefield.

Настроен Vitest, написаны unit-тесты для ядра модели поля: withinBounds, getCell, createBattlefield — 13 тестов, все проходят.

Введён BattleState и battleReducer с поддержкой действия OCCUPY_CELL.

Клик по клетке поля диспатчит OCCUPY_CELL — клетка переключается между свободной и занятой (toggle).

Занятые клетки визуально затемняются через CSS-класс battlefield-cell--occupied.

Клетки реализованы как <button> для соответствия стандартам доступности (a11y): поддержка клавиатурной навигации, корректная семантика.

Стили поля объединены в battlepage.css.
