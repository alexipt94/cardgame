# Cardgame

Веб-аналог карточной стратегии Rise of Mythos.  
Два игрока сражаются на поле из нескольких линий, разыгрывая карты существ и заклинаний.

## Статус

Проект в самом начале разработки.  
На текущем этапе настроен фронтенд-проект на React + TypeScript + Vite и создана базовая структура папок.

## Структура репозитория

- `client/` — фронтенд (React + TypeScript + Vite)
- `server/` — бэкенд (Node.js + Express + TypeScript, будет реализован позже)

## Планы

- реализовать базовое игровое поле и отображение карт на фронтенде;
- поднять сервер для управления матчами;
- подключить базу данных для хранения игроков, колод и результатов;
- добавить онлайн-режим через WebSocket.
